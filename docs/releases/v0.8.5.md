# y-sync v0.8.5

## 远端项目选择

- 登录后可浏览当前账号的远端项目，勾选项目并预览本地保存路径。
- 已接入项目禁止重复添加，检查本地目录嵌套及重叠；移除同步保留本地和远端文件。
- 首次同步按项目范围分页，各项目独立调度，避免大项目阻塞其他项目。

## 客户端自动更新

- 后台每天检查 GitHub Release，支持立即检查、关闭自动检查和跳过某个版本。
- 管理台显示更新说明、下载进度及安装状态；重复操作不会产生多个更新任务。
- 安装前校验 SHA256、匹配系统架构，macOS 桌面包同时验证应用标识与代码签名。
- 等待当前同步完成后暂存安装并自动重新启动；新守护进程健康检查失败时恢复旧版本并重新启动。
- 保留同步配置、数据、旧版本备份和更新日志。
- 桌面壳及随包守护进程注入一致版本号，发布产物包含 SHA256SUMS。

macOS 应用和 Unix CLI 守护支持自动重新启动；Windows CLI 安装后需要手动重新启动。旧版本首次升级至 v0.8.5 后即可使用本次完善的应用内更新流程。

## 运维与验证

- 已有服务部署前备份失败时立即停止，避免跳过备份后继续部署。
- 已验证下载完整性、损坏或中断下载保护、签名 DMG 暂存安装、更新鉴权与防重复、状态保存失败处理、进程重启及启动失败回滚。
- 已通过远端项目选择与多项目同步回归。
